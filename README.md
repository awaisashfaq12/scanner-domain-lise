# 🔍 Elite Domain Scanner (v2.0)
**Developed by: awais77**

Professional Domain Intelligence aur Owner details nikaalne ke liye ek advanced Termux tool. Ye tool Terminal (CLI) aur Web Dashboard (Localhost) dono ko support karta hai.

---

## ✨ Features
*   **Detailed Scan:** Registrar, Owner, Email, aur Expiry details nikaalta hai.
*   **Dual Mode:** Terminal mein results dikhata hai aur background mein `127.0.0.1:5000` par dashboard host karta hai.
*   **Rich UI:** Progress bars, colored tables, aur professional hacker-style interface.
*   **Multi-Domain Support:** Har kisam ke top-level domains ko scan karta hai.
